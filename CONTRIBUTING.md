# Contributing to RNForge Docs

Thanks for helping improve the RNForge docs site.

## Setup

- [bun](https://bun.sh) is required.
- Install dependencies: `bun install`
- Start the dev server: `bun run dev`

## Before opening a PR

- `bun run build` — site builds without errors
- `bun run typecheck` — TypeScript passes
- `bun run lint:links` — no broken links

## Issues

- Use the **Docs feedback** template for content suggestions.
- Use the **Bug report** template for docs-site bugs.
