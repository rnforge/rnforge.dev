# Security Policy

## Supported Versions

Only the latest deployed version of the RNForge docs site is supported.

## Reporting a Vulnerability

Please report security vulnerabilities privately to **security@rnforge.dev**.

Do not open public issues for security bugs.

## General Support

For docs content questions, site bugs, or public support, please open a GitHub issue.

If GitHub issues are not appropriate for your question, email **support@rnforge.dev**.
