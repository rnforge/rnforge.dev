Capability-first in-app update support for React Native.

- **Android**: Play Core immediate and flexible update flows
- **iOS**: Reports Android/Play-style update flows as unsupported
- **TypeScript**: Cross-platform typed API

## Features

- Check update availability and status
- Start immediate updates (Android)
- Start flexible updates with download progress (Android)
- Complete flexible updates after download (Android)
- Open store page as fallback
- Listen to install state events
