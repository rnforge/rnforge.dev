# Functions

## addInstallStateListener()

> **addInstallStateListener**(`listener`): `InstallStateSubscription`

Subscribe to install-state events (download progress, state changes, errors).

On Android, events are emitted during flexible update downloads and
install-state transitions. On iOS, the listener receives a typed
unsupported event and can be removed safely.

## Parameters

### listener

`InstallStateListener`

Callback invoked for each install-state event.

## Returns

`InstallStateSubscription`

A subscription handle. Call `remove()` to unsubscribe.

## completeFlexibleUpdate()

> **completeFlexibleUpdate**(): `Promise`\<`UpdateStatus`\>

Complete a flexible update after the download has finished.

Call this when `UpdateStatus.installStatus` is `'downloaded'`, typically
after receiving a `'flexible-update-downloaded'` event from
addInstallStateListener. On Android, this triggers the Play Core
install of the downloaded update.

## Returns

`Promise`\<`UpdateStatus`\>

The update status after the install is triggered.

## Throws

InAppUpdatesError on invalid input, native failures, bridge failures, or unexpected errors.

## startFlexibleUpdate()

> **startFlexibleUpdate**(`options?`): `Promise`\<`UpdateStatus`\>

Start a flexible update flow.

On Android, this triggers the Play Core flexible update download.
Use addInstallStateListener to track download progress.
After download completes, call completeFlexibleUpdate to install.

On iOS, returns an unsupported status (flexible updates are not available).

Precondition failures and other expected outcomes are returned as typed
results, not thrown errors. Only invalid input, bridge failures, and
unexpected failures throw InAppUpdatesError.

## Parameters

### options?

`StartFlexibleUpdateOptions`

Platform-specific options.

## Returns

`Promise`\<`UpdateStatus`\>

The update status after the flow starts or is rejected.

## Throws

InAppUpdatesError on invalid input, bridge failures, or unexpected errors.
