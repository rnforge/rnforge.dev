RNForge publishes small React Native packages for native platform features. The APIs stay narrow, expected states come back as typed results, and Android/iOS details stay explicit when you need them.

## Packages

### In-App Updates

`@rnforge/react-native-in-app-updates` checks update status, starts Android Play Core update flows, tracks flexible update progress, and opens the Play Store or App Store when an in-app flow is not available.
