---
title: RNForge
description: Small React Native packages that wrap native platform features without hiding platform rules.
---

RNForge publishes small React Native packages for native platform features. The APIs stay narrow, expected states come back as typed results, and Android/iOS details stay explicit when you need them.

Currently available:

### In-App Updates

`@rnforge/react-native-in-app-updates` — check update status, start Android Play Core update flows, track flexible update progress, and open the Play Store or App Store as a fallback.

[Open In-App Updates](/docs/in-app-updates)
