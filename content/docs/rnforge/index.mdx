Each package wraps a specific native capability behind a small TypeScript API. Expected states like unsupported platforms or missing store metadata come back as typed results, not thrown errors. Platform-specific details stay nested under explicit fields so you only reach for them when you need them.

## Packages

### In-App Updates

`@rnforge/react-native-in-app-updates` helps apps check update status, start Android Play Core update flows, track flexible update progress, and open the Play Store or App Store as a fallback.

Start with the package overview, then install the package and copy the quick start flow into your app.
