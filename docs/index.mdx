# RNForge Docs

RNForge provides native-layer wrapper packages for React Native.

## Packages

- [@rnforge/react-native-in-app-updates](./packages/react-native-in-app-updates) — Capability-first, cross-platform in-app update flows for Android (Play Core) with iOS store-page helpers. Supports immediate and flexible updates, install-state listeners, and typed unsupported-state handling.
