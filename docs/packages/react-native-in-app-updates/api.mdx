# API Reference

## Exported Functions

### `getUpdateStatus(options?)`

Check update availability and platform capabilities. Returns `Promise<UpdateStatus>`.

```ts
import { getUpdateStatus } from '@rnforge/react-native-in-app-updates'

const status = await getUpdateStatus({
  ios: { appStoreId: '1234567890', country: 'us' },
  android: { allowAssetPackDeletion: false },
})
```

**Platform:** Android + iOS

On **Android**, queries Play Core for update availability and returns `supported: true` when the app is Play-distributed. On **iOS**, performs an App Store lookup when `appStoreId` is provided; without it, returns `supported: false` with `reason: 'missing-app-store-id'`.

#### Options

```ts
type GetUpdateStatusOptions = {
  ios?: { appStoreId?: string; country?: string }
  android?: { allowAssetPackDeletion?: boolean }
}
```

### `startImmediateUpdate(options?)`

Starts an Android immediate update flow. Presents a full-screen Play Core dialog blocking user interaction until accepted or declined. Returns `Promise<UpdateStatus>`.

**Platform:** Android only. iOS returns `supported: false` with `reason: 'unsupported-platform'` (no exception).

```ts
import { startImmediateUpdate } from '@rnforge/react-native-in-app-updates'

const result = await startImmediateUpdate({
  android: { allowAssetPackDeletion: true },
})
```

### `completeFlexibleUpdate()`

Completes a downloaded flexible update. Call after `getUpdateStatus()` returns `installStatus: 'downloaded'` or after the install-state listener reports `installStatus: 'downloaded'`. Returns `Promise<UpdateStatus>`.

If no downloaded flexible update is pending, returns `reason: 'update-not-allowed'`.

**Platform:** Android only.

```ts
import { completeFlexibleUpdate } from '@rnforge/react-native-in-app-updates'

const result = await completeFlexibleUpdate()
```

### `addInstallStateListener(callback)`

Listen to Android flexible update download/install progress. Returns a `Subscription` object with a `remove()` method.

**Platform:** Android — events fire during the download/install lifecycle. iOS — fires a single event with `supported: false`, `reason: 'unsupported-platform'`, then becomes a noop subscription.

```ts
import { addInstallStateListener } from '@rnforge/react-native-in-app-updates'

const subscription = addInstallStateListener((event) => {
  console.log(event.installStatus)  // 'downloading' | 'downloaded' | 'failed' | ...
  console.log(event.bytesDownloaded) // number
  console.log(event.totalBytesToDownload) // number
  console.log(event.progress)        // 0.0 - 1.0
})

// Remove listener when done
subscription.remove()
```

#### Types

```ts
type InstallStateListener = (event: InstallStateEvent) => void

type InstallStateSubscription = {
  remove: () => void
}
```

### `openStorePage(options?)`

Opens the platform store page for the current app. Returns `Promise<void>`.

- **Android:** Opens `market://details?id=<packageName>` with browser fallback to Play Store. No options required.
- **iOS:** Requires `options.ios.appStoreId` (digits-only numeric ID). Optional `country` (two-letter lowercase code). Throws `InAppUpdatesError('invalid-input')` if `appStoreId` is missing or invalid.

```ts
import { openStorePage } from '@rnforge/react-native-in-app-updates'

// iOS
await openStorePage({
  ios: { appStoreId: '1234567890', country: 'us' },
})

// Android
await openStorePage()
```

#### Options

```ts
type OpenStorePageOptions = {
  ios?: { appStoreId: string; country?: string }
}
```

## Helper Predicates

Pure functions that return `boolean`. Branched on `UpdateStatus` fields — no try/catch needed.

```ts
import {
  isUpdateAvailable,
  canStartImmediateUpdate,
  canStartFlexibleUpdate,
  canCompleteFlexibleUpdate,
  canOpenStorePage,
  supportsInstallStateListener,
} from '@rnforge/react-native-in-app-updates'
```

| Helper | Returns `true` when |
|---|---|
| `isUpdateAvailable(status)` | `updateAvailable === true` |
| `canStartImmediateUpdate(status)` | `supported`, `capabilities.immediate`, `updateAvailable`, and `allowed.immediate` are all `true` |
| `canStartFlexibleUpdate(status)` | `supported`, `capabilities.flexible`, `updateAvailable`, and `allowed.flexible` are all `true` |
| `canCompleteFlexibleUpdate(status)` | `supported`, `capabilities.flexible`, and `installStatus === 'downloaded'` |
| `canOpenStorePage(status)` | `capabilities.storePage === true` (may be `true` even when `supported: false`) |
| `supportsInstallStateListener(status)` | `capabilities.installStateListener === true` |
